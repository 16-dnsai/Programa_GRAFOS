# Para crear de nuevo el entorno virtual debo de seguir los siguientes pasos
## Antes de crear el entorno, elimnamos .venv y seguimos los siguientes pasos 
### Creo el entorno virtual nuevamente con el mismo nombre 
  - Comando -> py -m venv .venv 
### Activación del entorno 
  - Comando -> source .venv/Scripts/activate
### Instalación de de todas las librerías y requerimientos 
  - comando -> pip install -r requirements.txt
